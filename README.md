# Arrow Escape 🎯

A minimalist logic puzzle mobile game built with Capacitor + React. Tap arrows to slide them off the grid — but every arrow blocks the others. Plan your order carefully.

> **400 BFS-validated levels · Daily puzzle · Infinite mode · 4 themes · iOS + Android**

---

## Gameplay

Each level presents a grid filled with directional arrows. Tap an arrow and it slides in the direction it points until it exits the board. The catch: **an arrow can't move if another arrow is in its path**. Clear all arrows to win.

- **3 hearts** per level — tapping a blocked arrow costs one
- **Hints** — reveals the next valid move
- **Stars** — earn up to 3 stars per level based on mistakes
- **Daily puzzle** — one unique puzzle per day, globally seeded
- **Infinite mode** — endless procedural puzzles at Easy / Medium / Hard

## Levels

| Range | Grid | Arrows | Difficulty |
|-------|------|--------|-----------|
| 1–80 | 4×4 | 4–5 | Easy |
| 81–170 | 5×5 | 5–7 | Medium |
| 171–270 | 6×6 | 7–9 | Hard |
| 271–400 | 7×7 | 10–12 | Expert |

Levels are generated by `scripts/generateLevels.mjs` using a BFS solver — every level is guaranteed solvable. Regenerate at any time:

```bash
node scripts/generateLevels.mjs
```

## Launch Checklist

### AdMob
1. Get App IDs and Ad Unit IDs from [AdMob console](https://admob.google.com)
2. Set `ADS_ENABLED = true` in `src/services/admob.ts`
3. Replace Ad Unit IDs in `admob.ts`
4. Update `GADApplicationIdentifier` in `ios/App/App/Info.plist`
5. Add `SKAdNetworkItems` entries for attribution

### RevenueCat / IAP
1. `npm install @revenuecat/purchases-capacitor`
2. Remove from `build.rollupOptions.external` in `vite.config.ts`
3. Add API keys in `src/services/iap.ts`
4. Create App Store products:
   - `arrow_escape_remove_ads` — $4.99 (non-consumable)
   - `arrow_escape_hints_20` — $0.99 (consumable)

### App Icons
Place icons in `ios/App/App/Assets.xcassets/AppIcon.appiconset/`

### Privacy Policy
Required for AdMob — host a page and link it in `src/screens/Settings.tsx`.

### App Store Metadata
- **Bundle ID:** `com.ronakbhatt.arrowescape`
- **Category:** Games → Puzzle
- **Age Rating:** 4+
- **Keywords:** puzzle, arrow, logic, grid, brain, minimalist

## Design System

Key design tokens:
```css
--bg              /* page background  */
--surface         /* card / panel     */
--accent          /* primary blue     */
--accent2         /* secondary purple */
--arrow-bg-from   /* tile gradient start */
--arrow-bg-to     /* tile gradient end   */
--arrow-glow      /* tile glow color  */
--hint            /* cyan hint color  */
--grad-primary    /* blue→purple CTA  */
```
